To add the domain `bcp.kanadhospital.org` to your Windows hosts file and point it to `127.0.0.1`, follow these steps:

1. Open Notepad as Administrator:
   - Click Start, type "Notepad".
   - Right-click on Notepad and select "Run as administrator".

2. In Notepad, open the hosts file:
   - Navigate to `C:\Windows\System32\drivers\etc\`.
   - In the file open dialog, choose "All Files" to see the hosts file.
   - Select the "hosts" file and open it.

3. Add a new line at the end of the file:
   ```
   127.0.0.1 bcp.kanadhospital.org
   ```

4. Save the file and close Notepad.

5. To make sure Windows uses the updated hosts file immediately, flush the DNS cache:
   - Open Command Prompt as Administrator.
   - Run the command:
     ```
     ipconfig /flushdns
     ```

Now, when you enter `https://bcp.kanadhospital.org` in your browser, it will resolve to your local machine (127.0.0.1).[1][2][4]

Here are step-by-step instructions to connect a Waitress/Django application to Nginx on Windows:

### Step 1: Install Nginx on Windows
- Download Nginx from the official site.
- Extract it to a folder, e.g., `C:\nginx`.
- Nginx config files will be in `C:\nginx\conf`.

### Step 2: Prepare Your Django Application
- Ensure your Django app is ready and using Waitress as the WSGI server.
- Run your app with Waitress on a chosen port (e.g., 8000):
  ```
  waitress-serve --port=8000 myproject.wsgi:application
  ```
- Confirm your app is reachable at `http://127.0.0.1:8000`.

### Step 3: Create Nginx Site Configuration
- Inside `C:\nginx\conf\`, create two folders: `sites-available` and `sites-enabled`.
- Create your site config file in `C:\nginx\conf\sites-available\yourproject.conf` with contents like:
  ```
  server {
      listen 80;
      server_name localhost;

      location /static/ {
          alias C:/path/to/your/django/static/;
      }

      location / {
          proxy_pass http://127.0.0.1:8000;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
      }
  }
  ```

### Step 4: Enable Site Configuration
- Create a symbolic link or shortcut in `C:\nginx\conf\sites-enabled` pointing to your config file in `sites-available`.
- On Windows Command Prompt (run as Administrator):
  ```
  mklink C:\nginx-1.29.1\conf\confsites-enabled\root.conf C:\nginx-1.29.1\conf\sites-available\root.conf
  mklink C:\nginx-1.29.1\conf\sites-enabled\root.conf C:\nginx-1.29.1\conf\sites-available\root.conf
  ```

### Step 5: Modify `nginx.conf` to Include Enabled Sites
- Edit `C:\nginx\conf\nginx.conf`.
- Inside the `http { ... }` block, add:
  ```
  include conf/sites-enabled/*;
  ```

### Step 6: Restart Nginx
- Open Command Prompt and navigate to `C:\nginx`.
- Run:
  ```
  nginx -s reload
  ```

### Step 7: Verify Setup
- Visit your server domain or localhost in a browser.
- Nginx should reverse proxy requests to Waitress/Django.

This setup uses 127.0.0.1 (localhost) to proxy traffic internally between Nginx and Waitress on Windows, organizing configurations under the `sites-available` and `sites-enabled` folders inside the Nginx `conf` directory for clarity and manageability.[7][8][10][11]
